پاک‌کننده متادیتای عکس ۱۰۰٪ آفلاین — بدون آپلود

متادیتای عکس را کامل پاک کن

عکس‌ها را همین‌جا در مرورگر بازسازی می‌کنیم: EXIF، موقعیت GPS، مدل دوربین، XMP و کامنت‌ها حذف می‌شوند. هیچ بایتی از دستگاه شما خارج نمی‌شود و به هیچ سروری وصل نمی‌شویم.

🔒 بدون آپلود ✈️ کاملاً آفلاین JPG · PNG · WebP MIT
عکس‌ها را اینجا رها کن
یا انتخاب کن — می‌توانی چند عکس را با هم بیندازی. هیچ فایلی آپلود نمی‌شود.
تنظیمات (اختیاری)

خروجی همیشه از پیکسل‌های تازه ساخته می‌شود، پس هیچ تگی زنده نمی‌ماند. کانواس مرورگر پروفایل رنگ ICC را حذف می‌کند؛ اگر تطابق دقیق رنگ مهم است از نسخه پایتون با --keep-icc استفاده کن.

چرا می‌توانی اعتماد کنی؟

🛡️تست کن که نمی‌توانم عکست را بفرستم

این صفحه با Content-Security-Policy محافظت می‌شود و مقدار connect-src آن 'none' است. یعنی مرورگر هر تلاش برای ارسال داده را رد می‌کند.

🧪چه چیزی حذف می‌شود؟

  • موقعیت GPS و مختصات دقیق
  • سریال دوربین، نام مالک، شماره لنز
  • تاریخ و ساعت اصلی عکس
  • مدل دستگاه، نسخه نرم‌افزار، تنظیمات عکاسی
  • XMP، IPTC، کامنت‌ها و بندانگشتی داخلی
  • پروفایل رنگ ICC (کانواس خروجی sRGB است)

⚙️آفلاین و نصب‌شدنی

با Service Worker کل برنامه کش می‌شود: می‌توانی اینترنت را کامل قطع کنی و همچنان کار کند. روی موبایل هم می‌توانی آن را به صفحه اصلی اضافه کنی.

💻برای صدها فایل و HEIC

برای پردازش گروهی سنگین، حفظ حرکت WebP، پروفایل رنگ دقیق و پشتیبانی HEIC آیفون از CLI پایتون استفاده کن. 

pip install image-metadata-cleaner
img-clean "photos/*.jpg" -o cleaned/ --jobs 4 --progress

پرسش‌های پرتکرار

آیا عکس‌هایم جایی ذخیره می‌شوند؟

نه. پردازش کاملاً داخل مرورگر انجام می‌شود. هیچ درخواست شبکه‌ای وجود ندارد و allow-list شبکه خالی است.

چرا عکس‌ها کوچک‌تر می‌شوند؟

هم متادیتا حذف می‌شود و هم تصویر دوباره فشرده می‌شود. مقدار کاهش برای هر فایل نشان داده می‌شود.

درباره WebP متحرک و HEIC چه؟

کانواس نمی‌تواند انیمیشن بسازد و مرورگرها HEIC را (به‌جز سافاری) رمزگشایی نمی‌کنند. برای این دو مورد از CLI استفاده کن؛ انیمیشن WebP کامل حفظ می‌شود.

الگوریتم دقیق چیست؟

تصویر روی یک canvas تازه کشیده می‌شود (با اصلاح جهت EXIF) و دوباره انکود می‌شود. فایل اصلی هرگز تغییر نمی‌کند.
